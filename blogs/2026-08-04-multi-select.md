You can now select multiple items at once across Outline and act on them together, instead of repeating the same action one row at a time. Documents – select multiple documents from search results or any document list to star, pin, archive, or otherwise batch-update them in a single action. Users, groups, and group members – the same selection model is now available in workspace settings, so admins can resend invites, activate, suspend, revoke, or remove several people or groups at once.
