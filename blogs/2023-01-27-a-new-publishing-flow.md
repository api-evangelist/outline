We've made some improvements to the publishing flow in Outline – you can now create a document without worrying about where to store it first. Before this update, you had to choose the location for a document before creating it, which could be frustrating for those who wanted to create a note quickly and worry about organizing it later. With the new publishing flow, you can create a document first and then choose where it will live in your knowledge base.
