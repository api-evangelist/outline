Outline can now import content from a few more sources, making it easier to bring existing notes and archives into your workspace. Web pages – import a page saved as MHTML ( .mhtml / .mht ) straight from your browser, images and all. Emails – import an .eml message and Outline will convert it to a document, using the email subject as the title.
