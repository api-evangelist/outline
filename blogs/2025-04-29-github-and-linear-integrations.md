We have rolled out an improved GitHub integration that allows embedding rich issue and pull request information directly into an Outline document. Not only that, but we've also added the same support for Linear , allowing seamless integration of Linear issues, GitHub PR's, and Outline documents. These new mentions will, of course, stay automatically up-to-date.
